# Descrizione per la consegna (art. 7.3)

Da incollare nel portale così com'è: 948 caratteri, limite 1.000. Il blocco qui sotto è il testo esatto.

```text
Agentonic is the colleague who rereads every meeting for you. Built for Italian SMEs and professional firms that live on meetings: project managers, purchasing, technicians. It reads minutes, transcripts and PDFs, compares them with earlier meetings and speaks first: the inverter quote went from 6,200 to 7,400 EUR, two deadlines slipped, and here is who is affected. It only proposes (new facts, tasks, deadline changes); a person approves or rejects, and every step is logged. It answers only from approved memory, cites the exact sentence, and says "I don't know" without a valid source. Role permissions apply before the model, so finance data never reaches a developer. Updates land in each person's to-do for the day. The model runs locally, so data stays in the company.
Pre-existing components: FastAPI, Pydantic, SQLite FTS5, pypdf, React 19, Vite, Tailwind, Qwen3-30B-A3B on LM Studio. All code written at the event; synthetic data.
```
